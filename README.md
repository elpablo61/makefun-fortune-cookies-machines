## The fortune

> You will hallucinate a library that never existed. A librarian named Ruth will shelve it anyway.

96 characters. One concept (hallucination), one named detail (Ruth), one turn that holds up on the second read.

## How it works

`main.ts` (Node 22) writes the single fortune line to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).

```sh
node main.ts
cat /output/entry.txt
```
